共創

パートナー・開発者の方へ

貴社のプロダクトを、
お客様のハードウェアへ。

データをクラウドに送れない組織は少なくありません。そのため、クラウド前提のAIプロダクトは届きません。ISHIZUEは、その入り口になります。貴社のプロダクトはプラグインとして、お客様が選んだモデルと並んで、お客様のマシンの上で動きます。プロダクトは、貴社のものです。

連携について相談する→ 組み込み方法を見る ↓

共創の考え方

明確な原則のもとで、パートナーに。

  1. 1

    プロダクトは、貴社のもの。

    コードも、ブランドも、ロードマップも貴社のままです。ISHIZUEは、それが動く場所です。

  2. 2

    モデルは、お客様が選ぶ。

    プラグインが隠れたモデルを持ち込むことはありません。考えるのは、お客様が動かしているモデルです。

  3. 3

    データの置き場所は、お客様が決める。

    お客様ご自身のMacとサーバーの上に。お客様が別の選択をしない限り。

共創の相手

さまざまな、つくり手と。

  • プロダクトを持つAIスタートアップ

    企業のお客様が、社内で動かしたいと考えるエージェント、コパイロット、ツール。

  • モデルと計算資源のつくり手

    モデルの開発企業、ワークステーションのメーカー、オンプレミスの計算資源を提供する企業。

  • システムインテグレーター

    日本の組織にAIを導入し、運用するチーム。

  • 企業の皆さま

    自社の業務に合わせたISHIZUEを、私たちと一緒につくりたい組織。

私たちが提供できること

私たちが持ち寄れるもの。

  • 貴社のプロダクトを、MCPサーバーやISHIZUEのプラグインとしてまとめる技術支援。
  • 自社のハードウェアでAIを動かしたい組織への、共同での提案。
  • 日本語の画面文言、ドキュメント、打ち合わせ。
  • セキュリティの審査担当者に示せる、ローカルファーストのルール。

はじめてのプラグイン

いちばん小さなプラグイン。

プラグインは、apply関数をエクスポートするTypeScriptのモジュールです。ISHIZUEはこの関数にコンテキストを渡し、プラグインはそれを通じて自分の機能を登録します。

export const name = 'hello-plugin'

export function apply(ctx) {
  // Anything registered through ctx is
  // cleaned up when the plugin unloads.
  console.log('[hello-plugin] plugin loaded!')
}

共有するときは、設定のレイヤーを指すバンドルとしてまとめ、プロファイルに追加します。

ライフサイクルと安全性

入れるのも、外すのも、きれいに。

  • リスナー、ツール、タイマーなど、プラグインが登録したものは、読み込みを解除すると自動で取り除かれます。
  • プラグインの読み込みに失敗しても、ISHIZUEはそのことを知らせ、そのプラグインなしで起動します。
  • プラグインは、フォルダ、パッケージファイル、パッケージレジストリ、Gitリポジトリから、手元のアプリに入れます。マーケットプレイスはありません。
  • プラグインのコードはアプリの中で、ワークスペースのサンドボックスの外で動きます。入れる前に内容を確認してください。
  • プラグインのツールごとの承認は、計画中です。現在、「変更前に確認する」設定はプラグインのツールには及びません。

始め方

最初のご相談から、最初のお客様まで。

  1. 1

    ご相談

    貴社のプロダクトの内容と、それを自社のハードウェアで使いたいお客様についてお聞かせください。

  2. 2

    技術的な適合

    MCPサーバー、プラグイン、スキルのうち、最適な組み込み方を一緒に検討します。

  3. 3

    開発と検証

    プロダクトをまとめる作業を支援し、実際のマシンと実際のモデルで検証します。

  4. 4

    提供

    ISHIZUEを使う組織へ、日本語と英語のドキュメントとともに届けます。

開発者プレビュー ライセンスを受けたチームが今使えるもの

  • TypeScriptのプラグインとバンドル。プロファイルに追加して使います。
  • プラグインとバンドルのオン・オフを切り替える「プラグイン」画面。
  • どの言語で書いたツールにも使える、MCPサーバーのバンドル。
  • 自社のコードからISHIZUEを操作するPython SDK。
  • ISHIZUEのドキュメントにある、段階を追った開発者向けガイド。

まだ提供していないもの

  • 一般向けのドキュメントとダウンロード。
  • プラグインのツールが宣言したリスクを読み取る承認のしくみ。
  • プラグインを共有する一般向けのディレクトリ。現在はありません。

開発者向けのドキュメントは、ライセンスを受けたチームとパートナーの皆さまに共有しています。
