A first plugin

The smallest possible plugin.

A plugin is a TypeScript module that exports an apply function. ISHIZUE calls it with a context, through which the plugin registers what it offers.

export const name = 'hello-plugin'

export function apply(ctx) {
  // Anything registered through ctx is
  // cleaned up when the plugin unloads.
  console.log('[hello-plugin] plugin loaded!')
}

To share it, package it as a bundle that points at a configuration layer, then add it to a profile.

Lifecycle and safety

Clean to add, clean to remove.

  • Anything a plugin registers, such as listeners, tools and timers, is removed automatically when it unloads.
  • If a plugin fails to load, ISHIZUE reports it and starts without it.
  • Plugins install into the local app from a folder, a packed package, a package registry or a Git repository. There is no marketplace.
  • Plugin code runs inside the app, outside the workspace sandbox. Review a plugin before installing it.
  • Approvals for individual plugin tools are planned. Today, ask-before-changes does not cover them.
